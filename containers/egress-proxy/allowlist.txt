# Base egress allow-list (AUDIT.md §4.2). One hostname per line; lines
# starting with # and blank lines are ignored. entrypoint.sh anchors each
# hostname (^host$) before handing it to tinyproxy's Filter, so entries
# here match exactly that hostname and nothing else (no substring or
# subdomain matches unless the subdomain is listed explicitly).
#
# Per-project overlays extend this list by adding another *.txt file to
# /etc/tinyproxy/allowlist.d/ in a derived image; entrypoint.sh
# concatenates every file in that directory at container start.
